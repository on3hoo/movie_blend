# Movie Blend

A movie recommendation system that combines the preferences of two users and recommends movies both users are likely to enjoy.

## Features
- Enter two favorite movies
- Blend user tastes
- Generate personalized recommendations
- Flask web interface

## Installation

git clone https://github.com/on3hoo/movie_blend.git
cd movie_blend

pip install -r requirements.txt

## Run

python app.py

## Technologies
- Python
- Flask
- Pandas
- Scikit-learn
